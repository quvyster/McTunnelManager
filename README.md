TMUS (TunnelManagerUltraSuper)

TMUS - умная утилита для проброса портов

Программа написана с помощью Deepseek V4 Pro(создание архитектуры, доработка), GPT-5.5(финальные исправления и сборка exe)
В качестве агента использовалось расширение vscode "Continue"
Провайдер апи ключа OpenRouter
Стоимость всех запросов использованных для разработки 4$

Для использования программы требуется:
1 Интернет
2 VPS, подойдут самые дешёвые тарифы с открытыми портами

Как пробросить порты:
1 Заполняете айпи сервера, имя пользователя(обычно root) и пароль пользователя
2 Добавляете порты которые требуется пробросить. Можно настроить порт локальный и публичный
3 Нажимаете подключиться (программа сама подключится к серверу, установит там нужные пакеты, сгенерирует ключи wireguard, пробросит порты и проверит соединение)
4 Если пробрасываете порты для мультиплеер игры, подключаться надо по айпи адресу VPS 

Рекомендую в качестве сервера использовать https://firstbyte.ru/ т.к. у них самые дешёвые стабильные сервера с полностью открытыми портами.
